17-18 자바
두 번째는 작품 리스트 페이지네이션 기능입니다. 작품 제목을 배열에 저장하고, 한 페이지에 6개씩 동적으로 생성합니다. 
현재 페이지에 해당하는 점이 바뀌고, 첫/마지막 페이지에서 버튼이 자동 비활성화되어 자연스러운 UI 인터랙션을 구현했습니다."

"⭐️ 특히, 모달 데이터 처리 시 some() 메서드를 활용했습니다. 
some()은 조건을 만족하는 요소를 찾으면 즉시 반복을 종료하기 때문에, 
모달 창에서 특정 작품 정보를 빠르게 탐색하고 렌더링하여 불필요한 반복 없이 퍼포먼스와 효율성을 높였습니다.

///////////////////////////////////////////////////
이 코드는 작품 리스트를 페이지 단위로 보여주는 자바스크립트 페이지네이션 기능입니다.

먼저, 작품 제목들을 workTitle 배열에 저장하고, 한 페이지에 여섯 개씩 보이도록 설정했습니다.
화면에는 작품 이미지와 제목이 자동으로 생성되고, 사용자는 하단의 점(dot) 이나 좌우 버튼을 클릭해서 페이지를 이동할 수 있습니다.

현재 페이지에 해당하는 점은 색상이 바뀌고, 첫 페이지나 마지막 페이지에서는 버튼이 자동으로 비활성화됩니다.
이런 기능을 통해 사용자가 많은 작품을 편리하게 탐색할 수 있고, UI 인터랙션이 한층 더 자연스럽게 느껴지도록 구현했습니다.

기술적으로는 JavaScript DOM 조작, 이벤트 제어, 동적 HTML 생성을 사용했습니다.

⭐️ 그리고 모달안에 데이터를 넣는 방법으로 some() 메서드를 활용하였습니다.
some()은 배열을 순회하면서 조건을 만족하는 요소를 찾으면 즉시 true를 반환하고 반복을 종료합니다.
이를 이용해 모달 창에서 특정 인덱스에 해당하는 작품 정보를 빠르게 탐색하고 렌더링할 수 있도록 구현했습니다.
즉, 불필요한 반복 없이 효율적으로 데이터를 처리해 퍼포먼스와 코드 효율성을 동시에 높였습니다.

"세 번째는 층별 전시관 지도를 동적으로 전환하는 기능입니다. 사용자가 층 버튼을 클릭하면 setActive() 함수가 실행되어 해당 층이 활성화됩니다."

"이때 선택된 층의 지도 이미지는 선명하게, 아래층은 블러 처리, 위층은 숨겨지도록 CSS 클래스를 전환하여, 마치 실제 건물의 층을 탐색하는 듯한 입체적인 
구조 효과를 주었습니다. 
이는 JavaScript의 dataset 속성과 DOM 조작을 통해 구현했습니다."

///////////////////////////////////////////////////////////////////
이 코드는 층별 전시관 지도를 동적으로 전환하고, 클릭한 층의 정보를 표시하는 인터랙션 기능입니다.

먼저, 상단의 label 요소를 클릭하면 data-url 속성을 읽어서 각 층별 페이지로 이동할 수 있도록 했습니다.
그리고 현재 페이지의 URL을 기준으로, 5층의 버튼이 자동으로 선택되도록 처리했습니다.

본격적인 플로어맵 기능은 setActive() 함수에서 이루어집니다.
사용자가 층 버튼을 클릭하면 해당 층이 활성화되고,
선택된 층의 지도 이미지는 선명하게 표시, 아래층은 흐릿하게 블러 처리, 위층은 숨겨지도록 설정했습니다.

이렇게 층별 이미지의 투명도와 필터를 조절해 입체적인 층 구조 효과를 주었습니다.

기술적으로는 JavaScript의 DOM 조작, dataset 속성 제어,
이벤트 리스너를 통한 인터랙션 처리,
그리고 CSS 클래스 전환을 활용했습니다.

사용자는 실제 건물의 층을 탐색하듯이,
클릭 한 번으로 각 층의 전시 내용을 직관적으로 확인할 수 있습니다.

20
"마지막 코드는 스크롤 위치를 감지해서 스타일을 동적으로 변경하는 기능입니다."

"스크롤 이벤트 발생 시 getBoundingClientRect() 메서드를 사용해 화면 하단 영역(.bottom-area)의 위치를 계산합니다. 
이 영역이 뷰포트 안에 들어오면 <main> 태그에 end 클래스를 추가하고, 벗어나면 클래스를 제거합니다."

"이처럼 페이지 끝부분에 도달했을 때 특정 요소의 색상이 바뀌거나 자연스럽게 페이드인되는 효과를 줄 수 있으며, 
스크롤 이벤트 최적화와 클래스 제어를 통해 사용자에게 부드러운 전환 경험을 제공합니다."

////////////////////////////////////////////////////////////////////
마지막으로 
이 코드는 스크롤 위치를 감지해서 특정 시점에 애니메이션이나 스타일을 바꾸는 기능입니다.

먼저, 화면 안에 있는 .bottom-area라는 요소의 위치를 가져오고,
사용자가 스크롤할 때마다 그 위치가 화면 아래쪽(viewport) 안으로 들어왔는지를 계산합니다.

만약 bottom-area가 화면 안에 들어오면 <main> 태그에 end 클래스를 추가하고,
다시 벗어나면 그 클래스를 제거합니다.

이렇게 하면 예를 들어, 페이지 끝부분에서 색상이 바뀌거나,
특정 섹션이 자연스럽게 페이드인(fade-in) 되는 효과를 줄 수 있습니다.

기술적으로는 JavaScript의 스크롤 이벤트, getBoundingClientRect() 메서드,
그리고 클래스 제어를 통한 DOM 조작을 활용했습니다
